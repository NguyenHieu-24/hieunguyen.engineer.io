THE PROBLEM

Why this project exists.

Allow users to enter CV information, save and retrieve records, and generate a PDF document.

IMPLEMENTATION

What the implementation includes.

  • Connected a Java Swing interface to SQL Server through JDBC.
  • Implemented parameterized insert and first-name lookup operations.
  • Integrated image attachment and PDF generation with iText.

CV Generator/src/ · CVs.sql

ARCHITECTURE

The data flow.

Desktop form→JDBC queries→SQL Server→PDF export

High-level illustration of the implemented workflow.

Desktop interface

The supplied application runs locally with Swing rather than in a browser.

Relational storage

The supplied schema includes an identity primary key and a unique email constraint.

PDF output

The document is generated from form values using iText.

EVIDENCE

Results and scope.

Academic project context: International University, VNU HCMC. The source supports record insertion, lookup, and PDF export. Database update/delete actions are not implemented in this snapshot.

NEXT ITERATION

Limitations and improvements.

  • Align the CVs table in the SQL script with the CV queries in Java.
  • Configure the SQL Server JDBC dependency and the GUI main class before building.
  • Move connection credentials out of source code.
  • The current single-table schema can be extended with related skill and employment tables.

REPRODUCE

Running the original project.

Open the Ant project in an appropriate Java IDE, configure SQL Server and JDBC, align table names, and run the cv.generator.CVs GUI class.

The portfolio package contains these case studies, not the original project datasets or services.
